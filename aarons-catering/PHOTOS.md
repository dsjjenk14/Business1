# Photo shot list

Every photo on the site is a real Aaron J's photo except the chef photo, which is cut from a
flyer and low resolution (send the original and it will look sharper). To swap any photo, save
the new one over the file in `site/images/` with the **same file name**, then update its
description in `src/content/photos.mjs` and run `node build.mjs`.

- Export as JPG, about 80% quality. Keep each file under 400 KB.
- Use the sizes below. A slightly different shape is fine; the layout crops to fit, so keep the
  subject near the center.
- Photos from a phone carry the location where they were taken. Re-saving them (as the photos
  here were) strips that out.

This file is generated by `node build.mjs` from `src/content/photos.mjs`.
